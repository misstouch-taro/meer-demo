# meer-demo

A small showcase repository for the **meer** desktop app — designed to demonstrate file previews, code highlighting, and a friendly browsing experience.

> **About meer**
> meer is a desktop app for Windows that lets you peek inside GitHub and GitLab repositories without using Git. Built for beginners and reviewers. → [misstouch-taro/meer](https://github.com/misstouch-taro/meer)

## Try it with meer

1. Open the meer app
2. Pick **GitHub** as the provider
3. Type **`misstouch-taro`** as the owner and click **Connect**
4. Select **`meer-demo`** from the repository dropdown
5. Browse the files on the left, click any to preview on the right

---

## Why this exists

Most people see GitHub for the first time and feel intimidated:

- Why is there so much text?
- Where's the actual content?
- How do I get this file onto my computer?

meer is built to remove all of that friction. This demo repo gives meer some friendly content to show off — so you can see how the app handles real-world files at a glance.
