# Features

A friendly overview of what **meer** can do.

## Core capabilities

### Browse public and private repositories
- Public mode works with no sign-in
- Private mode uses a Personal Access Token (PAT)

### Multi-provider support
| Provider | Hosted | Self-hosted |
|---|---|---|
| GitHub | ✅ github.com | ✅ GitHub Enterprise |
| GitLab | ✅ gitlab.com | ✅ self-hosted GitLab |

### Rich file preview
- Text files with syntax highlighting
- Markdown with both rendered and source views
- Images displayed inline

### Smooth downloads
- Single file via right-click → Download
- A whole branch as a ZIP archive

## Why it feels nice

- **No clone required** — open and read on the spot
- **Keyboard-friendly** — multi-select with Click / Ctrl+Click / Shift+Click
- **Lightweight** — a single window, no project setup
- **Multilingual** — English / 日本語 / Español

## Privacy first

Your token is encrypted locally with Windows DPAPI. The app sends nothing to its developer — no telemetry, no analytics.
